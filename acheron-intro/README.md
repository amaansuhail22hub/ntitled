# ACHERON — "Ahead of Time" intro (4K)

45-second animated brand intro, 2160×3840 (9:16 UHD), 24 fps, built from the
locked script. Everything is generated by code. The visuals, voiceover and
sound design use no stock footage and no sample libraries.

**Deliverable:** `out/ACHERON_AheadOfTime_4K.mp4` (H.264 High 5.1, BT.709, AAC 320k, -14 LUFS / -1 dBTP)
**Stems:** `out/stems/vo.wav` (voice only) and `out/stems/music_fx_no_vo.wav` (everything except the voice)

## Placeholders to replace before posting

1. **Logo.** The real Acheron files couldn't be reached from the build machine, so the mark and wordmark in this cut are stand-ins: a drawn dagger-cross and Cinzel SemiBold. Drop the real files in `assets/` and rebuild. The renderer picks them up automatically:
   - `assets/acheron-mark.png`: dagger-cross, point down, transparent PNG (or white on black)
   - `assets/acheron-wordmark.png`: the ACHERON wordmark. It gets split into letters on empty columns for the letter-by-letter build.
   - `assets/acheron-tagline.png`: the AHEAD OF TIME line
2. **Voice.** A TTS placeholder: Kokoro-82M (Apache-2.0), a blend of two low male voices (`am_michael` 55%, `am_onyx` 45%). It's tuned to the reference clip's pitch (≈103 Hz against 102 Hz) and gravel, close-mic with a light cathedral tail. "Acheron" is forced to /ˈækəɹɑːn/ ("A-kuh-ron"). For the human read, record each line as its own take, save as `build/vo_human/00.wav` … `20.wav` (line order = `timeline.VO`), and run `./make.sh --human`. Each take is trimmed and placed on its cue automatically.
3. **Drop date.** "NEW YEAR'S." is the date stand-in. Change it in `timeline.py` (`INVITE`) and the VO line 20.

## Rebuild

```bash
pip install numpy scipy opencv-python-headless pillow soundfile kokoro-onnx
# TTS model (only needed for the placeholder voice), ~350 MB:
mkdir -p build/models && cd build/models
curl -LO https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/kokoro-v1.0.onnx
curl -LO https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/voices-v1.0.bin
cd ../.. && ./make.sh
```

`python3 render.py --scale 0.5 --stills 10.6,28.3,37.5` dumps quick preview frames to `build/stills/`.
A full 4K render takes about 10 minutes on 4 cores.
